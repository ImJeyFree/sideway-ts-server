# 공개 및 배포 범위

## 공개 소스

main·TrayApp·HttpStreamer·UdpStreamer·TsBroadcaster(일반 버퍼/분배)·TunerClient·ScanClient·ChannelStore, SDK C 헤더, 일반 테스트와 모의 DLL, CMake, 배포 스크립트, 사용 문서를 Apache-2.0으로 공개합니다. nlohmann/json은 MIT 고지를 유지합니다.

## 비공개 코어

BDA 장치 제어, 주파수 검색, PAT/PMT/VCT 분석, 선택 서비스 PID·PAT 구성, 장치별 호환성 및 내부 진단은 별도 비공개 저장소에 보관합니다. 공개 빌드에는 해당 저장소의 경로·소스·헤더가 필요하지 않습니다.

DLL과 import LIB는 바이너리 조건으로 별도 배포합니다. 내부 PDB·OBJ·EXP·비공개 헤더·원본 진단 테스트는 배포하지 않습니다. `.lib`는 DLL에 연결하는 import library이며 정적 구현 라이브러리가 아닙니다.

## 세 가지 패키지

1. 공개 소스: 허용 목록의 파일만 포함합니다. Git 내부 디렉터리와 이력을 포함하지 않습니다.
2. 실행 패키지: 공개 서버 EXE, 실제 코어 DLL, 라이선스·고지·사용 문서.
3. SDK: 실제 코어 DLL, import LIB, C API 헤더·규격, 라이선스·고지.

모든 패키지에 파일별 SHA256 목록을 만들고 ZIP의 SHA256도 제공합니다. 코드 서명은 별도 인증서가 있을 때 수행하며 현재 패키지는 서명하지 않습니다.

## 공개 제외

실제 channels.json·녹화 TS·충돌 로그·장치 식별정보·내부 조사 문서·개인 경로·환경 파일·인증 및 서명 키·빌드 캐시·디버그 심볼·모의 DLL의 제품 패키지 혼입을 제외합니다.

Git 공개는 배포 폴더와 별개입니다. 추후 commit/push 전에 Git 전체 이력, 추적 파일, remote 및 staged diff를 다시 확인합니다. 비공개 코어에는 공개 원격을 연결하지 않습니다.
